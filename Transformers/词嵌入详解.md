# 词嵌入（Word Embedding）详解

## 📖 算子概述

**词嵌入（Word Embedding / Token Embedding）** 是 Transformer 模型的第一层，负责将离散的 token ID 转换为连续的向量表示。

**用途**：
- 将 token ID 映射为稠密向量
- 为模型提供可学习的语义表示
- 支持大规模词汇表的并行处理

**特点**：
- **查找表操作**：本质是索引查找（embedding lookup）
- **可学习参数**：通过训练学习语义表示
- **并行化支持**：支持张量并行（Tensor Parallelism）

---

## 🔢 公式与算法

### 数学公式

**词嵌入的基本操作**：

```
给定：
- 词汇表大小：V（vocab_size）
- 嵌入维度：D（embedding_dim）
- Token ID：i ∈ [0, V-1]

词嵌入矩阵：E ∈ R^(V × D)
输出向量：e_i = E[i, :]  ∈ R^D
```

**完整公式**：

```
对于输入序列：input_ids = [i₁, i₂, ..., iₙ]

输出嵌入：embeddings = [E[i₁], E[i₂], ..., E[iₙ]]  ∈ R^(n × D)
```

**矩阵形式**：

```
embeddings = E[input_ids, :]
```

其中 `E[input_ids, :]` 表示从嵌入矩阵 `E` 中按索引 `input_ids` 选择对应的行。

### 算法步骤

```
1. 输入：token IDs（整数序列）
2. 查找：从嵌入矩阵中查找对应的向量
3. 输出：嵌入向量序列
```

**伪代码**：

```python
def embedding_lookup(embedding_matrix, token_ids):
    """
    embedding_matrix: [vocab_size, embedding_dim]
    token_ids: [batch_size, seq_len]
    """
    # 从嵌入矩阵中按索引查找
    embeddings = embedding_matrix[token_ids]  # [batch_size, seq_len, embedding_dim]
    return embeddings
```

## 🧠 算法原理

### 1. 为什么需要词嵌入？

#### 问题：离散符号的挑战

**原始问题**：
- 文本是**离散的符号序列**（token IDs：0, 1, 2, ..., V-1）
- 神经网络需要**连续的数值输入**
- 离散符号之间没有数学关系（"cat" 和 "dog" 在数值上不相关）

**解决方案：词嵌入**
- 将每个 token 映射为**稠密向量**
- 向量在**语义空间**中具有几何关系
- 相似含义的 token 在向量空间中距离更近

#### 词嵌入的作用

1. **语义表示**：
   - 将离散符号转换为连续向量
   - 捕获词汇的语义信息

2. **可学习性**：
   - 嵌入矩阵是**可训练参数**
   - 通过反向传播学习最优表示

3. **维度统一**：
   - 所有 token 映射到相同的维度空间
   - 便于后续的矩阵运算

### 2. 词嵌入的工作原理

#### 查找表（Lookup Table）

**核心思想**：词嵌入本质上是一个**查找表（Lookup Table）**

```
嵌入矩阵 E：
┌─────────────────┐
│ E[0, :]  →  [0.1, 0.2, ..., 0.5]  (token 0 的嵌入)
│ E[1, :]  →  [0.3, 0.1, ..., 0.8]  (token 1 的嵌入)
│ E[2, :]  →  [0.5, 0.9, ..., 0.2]  (token 2 的嵌入)
│ ...             ...
│ E[V-1, :] → [0.7, 0.4, ..., 0.6]  (token V-1 的嵌入)
└─────────────────┘

输入：token_id = 2
输出：E[2, :] = [0.5, 0.9, ..., 0.2]
```

#### 前向传播过程

**步骤 1：输入 Token IDs**

```python
# 输入：token IDs（整数）
input_ids = torch.tensor([[101, 2023, 2003, 1037, 3231]])  # "the cat is a"
# shape: [batch_size=1, seq_len=5]
```

**步骤 2：嵌入查找**

```python
# 嵌入矩阵
embedding_matrix = torch.randn(vocab_size=50000, embedding_dim=768)
# shape: [vocab_size, embedding_dim]

# 查找操作
embeddings = embedding_matrix[input_ids]
# shape: [batch_size=1, seq_len=5, embedding_dim=768]
```

**步骤 3：输出嵌入向量**

```python
# 每个 token 现在是一个 768 维的向量
embeddings[0, 0, :]  # token 101 ("the") 的嵌入向量
embeddings[0, 1, :]  # token 2023 ("cat") 的嵌入向量
# ...
```

### 3. 词嵌入的学习过程

#### 训练时的更新

**反向传播**：
```
1. 前向传播：embeddings = E[input_ids]
2. 计算损失：loss = compute_loss(embeddings, ...)
3. 反向传播：∂loss/∂E
4. 更新参数：E ← E - α * ∂loss/∂E
```

**关键点**：
- 只有**被使用的 token** 的嵌入会被更新
- 相似上下文中出现的 token 会学习到相似的嵌入
- 通过大量文本训练，嵌入捕获了语义和语法信息

## 💻 代码实现

### Transformers 中的实现

#### PyTorch 标准实现

```python
import torch
import torch.nn as nn

class Embedding(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
    
    def forward(self, input_ids):
        # input_ids: [batch_size, seq_len]
        # 返回: [batch_size, seq_len, embedding_dim]
        return self.embedding(input_ids)
```

**PyTorch 的 `nn.Embedding`**：
- 内部实现为查找表
- 支持梯度更新
- 支持稀疏梯度（只更新使用的 token）

#### Hugging Face Transformers 中的使用

```python
from transformers import AutoModel

model = AutoModel.from_pretrained("bert-base-uncased")

# 获取嵌入层
embedding_layer = model.embeddings.word_embeddings
# 或者
embedding_layer = model.get_input_embeddings()

# 使用
input_ids = torch.tensor([[101, 2023, 2003]])
embeddings = embedding_layer(input_ids)
```

### SGLang 中的实现

#### VocabParallelEmbedding

SGLang 使用 `VocabParallelEmbedding` 实现词嵌入，支持**张量并行（Tensor Parallelism）**。

**源码位置**：
`python/sglang/srt/layers/vocab_parallel_embedding.py`

#### 核心代码解析

**1. 初始化**

```python
class VocabParallelEmbedding(torch.nn.Module):
    def __init__(
        self,
        num_embeddings: int,      # 词汇表大小
        embedding_dim: int,        # 嵌入维度
        params_dtype: Optional[torch.dtype] = None,
        org_num_embeddings: Optional[int] = None,
        padding_size: int = DEFAULT_VOCAB_PADDING_SIZE,  # 默认 64
        quant_config: Optional[QuantizationConfig] = None,
        enable_tp: bool = True,    # 是否启用张量并行
    ):
        super().__init__()
        
        # 张量并行相关
        if enable_tp:
            tp_rank = get_tensor_model_parallel_rank()
            self.tp_size = get_tensor_model_parallel_world_size()
        else:
            tp_rank = 0
            self.tp_size = 1
        
        self.num_embeddings = num_embeddings
        self.embedding_dim = embedding_dim
        
        # 计算每个分片的词汇表范围
        self.shard_indices = self._get_indices(...)
        
        # 创建嵌入权重（分片）
        self.quant_method.create_weights(
            self,
            self.embedding_dim,
            [self.num_embeddings_per_partition],  # 分片后的词汇表大小
            self.embedding_dim,
            self.num_embeddings_padded,
            params_dtype=params_dtype,
        )
```

**关键点**：
- **词汇表分片**：将词汇表按 `tp_size` 分片，每个 GPU 只存储一部分
- **Padding**：将词汇表大小填充到 64 的倍数（便于并行）
- **量化支持**：支持量化嵌入（减少内存）

**2. 前向传播**

```python
def forward(self, input_):
    if self.tp_size > 1:
        # 张量并行模式：构建掩码，只处理本分片的 token
        masked_input, input_mask = get_masked_input_and_mask(
            input_,
            self.shard_indices.org_vocab_start_index,
            self.shard_indices.org_vocab_end_index,
            self.shard_indices.num_org_vocab_padding,
            self.shard_indices.added_vocab_start_index,
            self.shard_indices.added_vocab_end_index,
        )
    else:
        masked_input = input_
    
    # 嵌入查找
    output_parallel = self.quant_method.embedding(self, masked_input.long())
    
    if self.tp_size > 1:
        # 掩码处理：不属于本分片的 token 输出设为 0
        output_parallel.masked_fill_(input_mask.unsqueeze(-1), 0)
        
        # All-reduce：聚合所有分片的结果
        output_parallel = tensor_model_parallel_all_reduce(output_parallel)
    
    return output_parallel
```

**张量并行的工作原理**：

假设 `vocab_size=50000`, `tp_size=4`：

```
Rank 0: 处理 token [0, 12500)     → 存储 E[0:12500, :]
Rank 1: 处理 token [12500, 25000) → 存储 E[12500:25000, :]
Rank 2: 处理 token [25000, 37500) → 存储 E[25000:37500, :]
Rank 3: 处理 token [37500, 50000) → 存储 E[37500:50000, :]
```

**查找过程**：
1. 每个 rank 只查找自己分片内的 token
2. 其他 token 的输出设为 0
3. 通过 All-reduce 聚合所有分片的结果

**3. 掩码构建函数**

```python
@torch.compile(dynamic=True, backend=get_compiler_backend())
def get_masked_input_and_mask(
    input_: torch.Tensor,
    org_vocab_start_index: int,
    org_vocab_end_index: int,
    num_org_vocab_padding: int,
    added_vocab_start_index: int,
    added_vocab_end_index: int,
) -> Tuple[torch.Tensor, torch.Tensor]:
    # 判断 token 是否属于原始词汇表范围
    org_vocab_mask = (input_ >= org_vocab_start_index) & (input_ < org_vocab_end_index)
    
    # 判断 token 是否属于新增词汇表范围（LoRA）
    added_vocab_mask = (input_ >= added_vocab_start_index) & (input_ < added_vocab_end_index)
    
    # 计算偏移量
    added_offset = added_vocab_start_index - (org_vocab_end_index - org_vocab_start_index) - num_org_vocab_padding
    
    # 调整输入索引（映射到本地分片索引）
    valid_offset = (org_vocab_start_index * org_vocab_mask) + (added_offset * added_vocab_mask)
    vocab_mask = org_vocab_mask | added_vocab_mask
    input_ = vocab_mask * (input_ - valid_offset)
    
    return input_, ~vocab_mask  # 返回调整后的输入和掩码
```

class LlamaModel(nn.Module):

        # 后续处理...
        return hidden_states

## 🎯 设计要点

### 1. 为什么需要 Padding？

**Padding 的作用**：
- **对齐内存**：确保词汇表大小是 64 的倍数
- **并行效率**：便于 GPU 并行处理
- **分片对齐**：确保每个分片大小相等

**示例**：
```python
vocab_size = 50000
padding_size = 64
padded_vocab_size = ((50000 + 64 - 1) // 64) * 64 = 50048
```

### 2. 张量并行的优势

**内存节省**：
- 原始：`50000 × 4096 × 4 bytes = 819 MB`（单 GPU）
- 并行（4 GPUs）：`12500 × 4096 × 4 bytes = 205 MB`（每 GPU）

**通信开销**：
- 每次前向传播需要一次 All-reduce
- 但相比内存节省，开销可接受

### 3. LoRA 支持

**LoRA（Low-Rank Adaptation）**：
- 支持在原始词汇表基础上添加新 token
- 新增 token 的嵌入放在分片的末尾
- 通过掩码机制区分原始 token 和新增 token

**布局示例**（见代码注释）：
```
TP1, rank 0:
|< --------BASE-------- >|< -BASE PADDING-- >|< -----LORA------ >|< -LORA PADDING-- >|
token_id: |  0  |  1  | ... | 1009 |  -1  | ... |  -1  | 1010 | ... | 1015 |  -1  | ... |  -1  |
```

### 4. 量化支持

**量化嵌入**：
- 支持 FP8、INT8 等量化格式
- 通过 `quant_method.embedding()` 实现
- 减少内存占用和带宽需求

## 📊 性能分析

### 计算复杂度

**时间复杂度**：
- **查找操作**：O(1)（索引访问）
- **内存访问**：O(seq_len × embedding_dim)
- **All-reduce**：O(seq_len × embedding_dim × log(tp_size))

**空间复杂度**：
- **嵌入矩阵**：O(vocab_size × embedding_dim)
- **分片后**：O(vocab_size × embedding_dim / tp_size)

### 内存访问模式

**特点**：
- **随机访问**：根据 token ID 随机访问嵌入矩阵
- **缓存不友好**：大词汇表导致缓存命中率低
- **带宽受限**：主要瓶颈是内存带宽

**优化策略**：
1. **分片**：减少每个 GPU 的内存占用
2. **量化**：减少每个嵌入向量的字节数
3. **预取**：提前加载可能用到的嵌入

## 🔍 简化版本（不依赖 SGLang）

如果你想理解核心逻辑，这里是纯 PyTorch 版本：

```python
import torch
import torch.nn as nn

class SimpleEmbedding(nn.Module):
    """简化的词嵌入实现"""
    
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        # 创建嵌入矩阵，随机初始化
        self.embedding = nn.Parameter(
            torch.randn(vocab_size, embedding_dim) * 0.02
        )
    
    def forward(self, input_ids):
        """
        Args:
            input_ids: [batch_size, seq_len] - token IDs
        
        Returns:
            embeddings: [batch_size, seq_len, embedding_dim] - 嵌入向量
        """
        # 从嵌入矩阵中查找对应的向量
        embeddings = self.embedding[input_ids]
        return embeddings

# 使用示例
vocab_size = 50000
embedding_dim = 768
batch_size = 4
seq_len = 128

# 创建嵌入层
embedding = SimpleEmbedding(vocab_size, embedding_dim)

# 输入 token IDs
input_ids = torch.randint(0, vocab_size, (batch_size, seq_len))

# 前向传播
embeddings = embedding(input_ids)
print(f"Input shape: {input_ids.shape}")           # [4, 128]
print(f"Output shape: {embeddings.shape}")         # [4, 128, 768]
```

## 📚 扩展阅读

### 1. 位置编码（Position Embedding）

词嵌入通常与位置编码结合使用：

```python
# 词嵌入
token_embeddings = embedding(input_ids)  # [batch, seq_len, hidden_size]

# 位置编码
position_embeddings = position_embedding(positions)  # [batch, seq_len, hidden_size]

# 相加
hidden_states = token_embeddings + position_embeddings
```

### 2. 预训练嵌入 vs 随机初始化

**预训练嵌入**：
- 从预训练模型加载
- 已经学习了语义信息
- 适合迁移学习

**随机初始化**：
- 从零开始训练
- 需要更多数据和时间
- 适合特定领域任务

### 3. 嵌入维度选择

**常见维度**：
- **小模型**：128, 256, 512
- **中等模型**：768, 1024
- **大模型**：2048, 4096, 8192

**权衡**：
- 维度越大：表达能力越强，但内存和计算开销越大
- 维度越小：效率更高，但可能丢失信息

### 4. 不同类型的嵌入

#### Token Embedding（词嵌入）
- 将 token ID 转换为向量
- 本文主要讨论的内容

#### Position Embedding（位置嵌入）
- 编码 token 在序列中的位置
- 可以是可学习的或固定的（如正弦位置编码）

#### Segment Embedding（段落嵌入）
- 用于区分不同的输入段落（如 BERT）
- 在单段落任务中不需要

#### Type Embedding（类型嵌入）
- 用于区分不同类型的输入（如视觉-语言模型）

### 5. 嵌入的初始化方法

**常见初始化方法**：

```python
# 1. 正态分布初始化
nn.init.normal_(embedding.weight, mean=0, std=0.02)

# 2. 均匀分布初始化
nn.init.uniform_(embedding.weight, a=-0.1, b=0.1)

# 3. Xavier/Glorot 初始化
nn.init.xavier_uniform_(embedding.weight)

# 4. 从预训练模型加载
embedding.load_state_dict(pretrained_embedding.state_dict())
```
