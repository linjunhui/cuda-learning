# 4. 表达时的小提示

4. 表达时的小提示
•
保持自然：避免使用过于夸张的言辞。真诚、具体的表述比华丽的赞美更打动人。
•
关注细节：尽量谈论具体的物品、行为或细节，这比评价抽象的个人特质（如“你好有气质”）更
显真诚，也更容易把握。
•
尊重他人感受：特别是对不太熟悉的人，尽量避免评价对方的外貌身材等敏感话题。夸赞对方的发
型、配饰、衣着搭配或精神面貌是更安全的选择。
•
不必期待即时回馈：表达欣赏主要是传递一份善意和关注。对方可能只是简单地道谢或谦虚一下，
这很正常。你的心意已经传达到位了。
真诚地表达欣赏，本质上是一种关注和认可。它不需要华丽的辞藻，只需要一颗愿意发现美好的心，
和一份将它说出来的自然。
