## 🔑 关键优化技巧速查

### 技巧 1：向量化访问

```cpp
// 适用场景：连续内存访问
float4 reg = FLOAT4(data[idx]);  // 一次加载 4 个元素
```

**适用题目**：elementwise, relu, sigmoid, gelu, layer-norm...

---

### 技巧 2：共享内存缓存

```cpp
__shared__ float shared[256];
shared[threadIdx.x] = global_data[threadIdx.x];
__syncthreads();
```

**适用题目**：reduce, layer-norm, softmax...

---

### 技巧 3：Warp-level Reduction

```cpp
int value = input[threadIdx.x];
for (int offset = 16; offset > 0; offset /= 2) {
    value += __shfl_down_sync(0xffffffff, value, offset);
}
```

**适用题目**：reduce, layer-norm, softmax...

---

### 技巧 4：融合操作

```cpp
// 将多个操作融合为单个 kernel
// 例如：norm + activation
```

**适用题目**：layer-norm + activation, 各种组合...

## 💡 优化学习建议

### 1. 系统化方法

**不要盲目优化**：
1. ✅ 先理解硬件特性
2. ✅ 识别性能瓶颈
3. ✅ 针对瓶颈优化
4. ✅ 验证优化效果

### 2. 对比学习

**对比不同版本**：
- 基础版本 vs 优化版本
- 不同优化程度的版本
- 不同优化技巧的版本

**分析差异**：
- 性能差异的原因
- 优化技巧的效果
- 代码复杂度的权衡

### 3. 迭代优化

**渐进式优化**：
```
基础版本
  ↓ (+20%)
向量化版本
  ↓ (+30%)
共享内存版本
  ↓ (+50%)
综合优化版本
```

### 4. 记录学习

**建立学习笔记**：
- 每个优化技巧的记录
- 性能提升的数据
- 遇到的问题和解决方案
