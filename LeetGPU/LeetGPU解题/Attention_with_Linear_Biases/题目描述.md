# 🤖 Attention with Linear Biases ($\text{ALiBi}$)

**难度：** $\text{Medium}$

实现 **Attention with Linear Biases ($\text{ALiBi}$)**，遵循论文《Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation》中所描述的方法，对给定矩阵进行计算。

---

## 📐 公式与输入

给定 **Query** 矩阵 $\mathbf{Q}$ (尺寸 $\mathbf{M \times d}$)，**Key** 矩阵 $\mathbf{K}$ (尺寸 $\mathbf{N \times d}$)，以及 **Value** 矩阵 $\mathbf{V}$ (尺寸 $\mathbf{N \times d}$)，你的程序应该使用以下公式计算输出矩阵 $\mathbf{O}$:

$$
\mathbf{O} = \text{Softmax}\left(\mathbf{Q} \mathbf{K}^{\text{T}} + \alpha \cdot \mathbf{\Delta}\right) \mathbf{V}
$$

其中：

* $\mathbf{\alpha}$ 是控制线性偏置的**斜率 (slope)**。
* $\mathbf{\Delta} = \mathbf{i} - \mathbf{j}$ 表示 $\text{Query}$ $\mathbf{i}$ 和 $\text{Key}$ $\mathbf{j}$ 之间的**相对位置**。
* $\text{Softmax}$ 函数是**行式 (row-wise)** 应用的。

### 数据类型和尺寸

| 变量 | 含义 | 类型 | 尺寸 |
| :--- | :--- | :--- | :--- |
| $\mathbf{Q}$ | Query 矩阵 | $\text{float32}$ | $M \times d$ |
| $\mathbf{K}$ | Key 矩阵 | $\text{float32}$ | $N \times d$ |
| $\mathbf{V}$ | Value 矩阵 | $\text{float32}$ | $N \times d$ |
| $\mathbf{O}$ | Output 矩阵 | $\text{float32}$ | $M \times d$ |
| $\mathbf{\alpha}$ | 线性偏置斜率 | $\text{float32}$ | 标量 |
| $\mathbf{M}, \mathbf{N}, \mathbf{d}$ | 维度 | $\text{int32}$ | |

## 🛠️ 实现要求

1.  **限制：** 只能使用原生功能（不允许使用外部库，如 $\text{numpy}$, $\text{torch}$, $\text{cuBLAS}$ 等，暗示需要手动实现 $\text{GEMM}$ 和 $\text{Softmax}$）。
2.  **函数签名：** $\text{solve}$ 函数签名必须保持不变。
3.  **结果存储：** 最终结果必须存储在 $\mathbf{output}$ 矩阵中。

### 约束条件

* $1 \le \mathbf{M}, \mathbf{N} \le 2048$
* $1 \le \mathbf{d} \le 1024$
* $-1.0 \le \mathbf{\alpha} \le 1.0$

---

## 📝 核心步骤分解

要实现 $\text{ALiBi}$，你需要完成以下三个核心矩阵操作：

1.  **计算 Attention Logits ($\mathbf{A}$):**
    $$
    \mathbf{A} = \mathbf{Q} \mathbf{K}^{\text{T}} + \alpha \cdot \mathbf{\Delta}
    $$
2.  **计算 $\text{Attention}$ 权重矩阵 ($\mathbf{P}$):**
    $$
    \mathbf{P} = \text{Softmax}_{\text{row-wise}}(\mathbf{A})
    $$
3.  **计算最终输出 ($\mathbf{O}$):**
    $$
    \mathbf{O} = \mathbf{P} \mathbf{V}
    $$
