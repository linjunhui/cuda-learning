# Python加强目录

> 系统学习 Python 编程语言，从基础语法到高级特性

## 📚 学习路径

### 第一阶段：基础技能建设（3个月）

#### 01-基础语法
- **学习时间**：1个月
- **学习目标**：熟练掌握Python基本语法和特性
- **主要内容**：
  - Python基础语法（变量、数据类型、运算符）
  - 控制流语句（条件、循环）
  - 函数定义和调用（参数、返回值、作用域）
  - 内置数据结构（列表、字典、集合、元组）
  - 文件操作和异常处理
  - 模块和包的使用
- **实践项目**：
  - 实现简单的数据处理脚本
  - 完成文件操作和数据处理任务
  - 编写异常安全的Python程序

#### 02-面向对象
- **学习时间**：1个月
- **学习目标**：深入理解Python面向对象编程
- **主要内容**：
  - 类和对象基础
  - 封装、继承、多态
  - 特殊方法（`__init__`、`__str__`、`__repr__`等）
  - 属性访问和描述符
  - 抽象基类和接口
  - 设计模式（Python实现）
- **实践项目**：
  - 实现设计模式示例
  - 重构代码应用设计原则
  - 设计小型软件系统架构

#### 03-数据结构算法
- **学习时间**：1个月
- **学习目标**：熟练掌握常用数据结构和算法
- **主要内容**：
  - Python内置数据结构深入理解
  - 线性数据结构（数组、链表、栈、队列）
  - 树形数据结构（二叉树、AVL树、堆）
  - 图算法
  - 排序和搜索算法
  - 动态规划
  - 算法复杂度分析
- **实践项目**：
  - 实现常用数据结构
  - 完成LeetCode中等难度题目50道
  - 分析算法复杂度

## 📊 项目评估标准

### 考察点

项目评估将从以下7个维度进行考察：

1. **功能健全**
   - 功能完整性
   - 功能正确性
   - 边界条件处理
   - 错误处理

2. **AI辅助提效**
   - 合理使用AI工具辅助开发
   - 代码生成效率
   - 问题解决效率
   - AI工具使用记录

3. **编码规范性**
   - 遵循PEP 8编码规范
   - 代码可读性
   - 命名规范
   - 代码结构清晰
   - 注释和文档完整

4. **SDD掌握程度**（Software Design Document，软件设计文档）
   - 设计文档完整性
   - 架构设计合理性
   - 接口设计规范
   - 设计模式应用
   - 设计文档质量

5. **异常保护**
   - 异常处理完整性
   - 异常类型选择合理
   - 异常信息准确
   - 资源清理（finally/上下文管理器）
   - 防御性编程

6. **性能设计**
   - 算法复杂度分析
   - 性能优化考虑
   - 数据结构选择合理
   - 性能测试和评估
   - 瓶颈识别和优化

7. **并发控制**
   - 并发场景识别
   - 线程安全处理
   - 锁机制使用
   - 并发性能优化
   - 死锁和竞态条件避免

### 淘汰标准

项目评估采用以下淘汰机制，满足任一条件即被淘汰：

1. **提交产物缺失淘汰**
   - 缺少必要代码文件
   - 缺少项目文档
   - 缺少配置文件
   - 项目结构不完整

2. **未包含UT用例淘汰**（Unit Test，单元测试）
   - 未提供单元测试代码
   - 测试文件缺失
   - 测试框架未配置

3. **全量代码覆盖率未达标淘汰**
   - 代码覆盖率低于要求阈值（具体阈值根据项目确定）
   - 核心功能未覆盖
   - 关键路径未测试

4. **准入测试用例达不到50%通过率淘汰**
   - 准入测试通过率低于50%
   - 核心功能测试失败
   - 基础功能无法正常运行

### 评估要求

- 所有项目必须包含完整的单元测试（UT）
- 代码覆盖率需达到项目要求（建议80%以上）
- 必须通过至少50%的准入测试用例
- 提交产物需完整，包括代码、文档、测试等

## 学习建议

1. **理论与实践结合**：每学习一个概念都要通过编程实践来巩固
2. **循序渐进**：按照计划逐步推进，不要急于求成
3. **项目驱动**：通过实际项目来综合运用所学知识
4. **持续学习**：Python生态丰富，要保持学习的习惯
5. **代码规范**：遵循PEP 8编码规范，养成良好的编程习惯
