# Level 1: 基础模块 (Basics)

本级别包含 SGL Kernel 中最基础的模块，适合初学者学习。这些模块虽然简单，但构成了整个框架的基础，理解它们对后续学习至关重要。

## 📚 模块列表

1. **[Elementwise 逐元素操作](./01-elementwise.md)** ⭐
   - 激活函数（SiLU, GELU）
   - RMS 归一化
   - 旋转位置编码（RoPE）
   - Top-K 选择

2. **[Memory 内存管理](./02-memory.md)**
   - KV 缓存存储
   - 弱引用张量
   - 内存优化技巧

3. **[Grammar 语法约束](./03-grammar.md)**
   - 语法约束解码
   - 位掩码应用
   - JSON/代码生成支持

## 🎯 学习目标

完成本级别的学习后，您应该能够：

- ✅ 理解基础的 CUDA 内核编写模式
- ✅ 掌握向量化内存访问技术
- ✅ 理解融合操作的重要性
- ✅ 了解 GPU 内存管理基础
- ✅ 掌握简单的条件分支优化

## 📖 学习路径

建议按顺序学习：

1. **从 Elementwise 开始** - 理解最基础的 GPU 操作
2. **学习 Memory 管理** - 掌握内存访问优化
3. **了解 Grammar 约束** - 理解特定应用场景
