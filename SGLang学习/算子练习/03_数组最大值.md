## 实现步骤

### 步骤1：单块归约

```cuda

    __shared__ float sdata[256];
    
    int tid = threadIdx.x;
    int idx = tid;
    
    // 加载数据
    sdata[tid] = (idx < n) ? input[idx] : -INFINITY;
    __syncthreads();
    
    // 归约循环
    for (int s = blockDim.x / 2; s > 0; s >>= 1) {
        if (tid < s) {
            sdata[tid] = fmaxf(sdata[tid], sdata[tid + s]);
        }
        __syncthreads();
    }
    
    // 输出结果
    if (tid == 0) {
        output[0] = sdata[0];
    }
}
```

## 提示

1. **归约算法原理**：
   - 每个线程块独立处理一部分数据
   - 使用树形结构逐步归约
   - 每次迭代将数据量减半

2. **共享内存使用**：
   ```cuda
   __shared__ float sdata[256];  // 每个线程块有自己的共享内存
   ```

3. **同步点**：
   ```cuda
   __syncthreads();  // 确保所有线程完成当前阶段
   ```

4. **最大值比较**：
   ```cuda
   sdata[tid] = fmaxf(sdata[tid], sdata[tid + s]);
   ```
