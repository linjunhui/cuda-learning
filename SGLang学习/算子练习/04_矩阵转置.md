# 练习题目 04：矩阵转置

## 题目描述

实现一个 CUDA 内核函数，对矩阵进行转置操作。

**功能要求**：
- 实现 `matrixTranspose` 内核函数，将 `M×N` 矩阵转置为 `N×M` 矩阵
- 使用共享内存优化性能（避免非合并访问）
- 支持任意大小的矩阵
- 验证转置的正确性

## 知识点

- 矩阵转置算法
- 内存访问模式（合并访问 vs 非合并访问）
- 共享内存的使用
- 二维线程索引
- 内存合并优化

## 实现要求

### 方法1：简单转置（可能有性能问题）

```cuda
__global__ void matrixTransposeSimple(float *input, float *output, 
                                      int width, int height) {
    int col = blockIdx.x * blockDim.x + threadIdx.x;
    int row = blockIdx.y * blockDim.y + threadIdx.y;
    
    if (row < height && col < width) {
        // 直接转置（可能导致非合并访问）
        output[col * height + row] = input[row * width + col];
    }
}
```

### 方法2：使用共享内存优化（推荐）

```cuda
__global__ void matrixTransposeOptimized(float *input, float *output,
                                         int width, int height) {
    // 使用共享内存作为缓存
    __shared__ float tile[16][17];  // 注意：17 用于避免 bank conflict
    
    // 计算原始矩阵中的位置
    int x = blockIdx.x * blockDim.x + threadIdx.x;
    int y = blockIdx.y * blockDim.y + threadIdx.y;
    
    // 计算转置后的位置
    int x_t = blockIdx.y * blockDim.y + threadIdx.y;
    int y_t = blockIdx.x * blockDim.x + threadIdx.x;
    
    // 加载数据到共享内存（合并访问）
    if (x < width && y < height) {
        tile[threadIdx.y][threadIdx.x] = input[y * width + x];
    }
    
    __syncthreads();
    
    // 从共享内存写回（合并访问）
    if (x_t < height && y_t < width) {
        output[y_t * height + x_t] = tile[threadIdx.x][threadIdx.y];
    }
}
```

## 提示

1. **转置公式**：
   ```
   如果 input[i][j] = value
   那么 output[j][i] = value
   ```

2. **共享内存大小**：
   ```cuda
   __shared__ float tile[TILE_SIZE][TILE_SIZE + 1];  // +1 避免 bank conflict
   ```

3. **二维线程索引**：
   ```cuda
   int x = blockIdx.x * blockDim.x + threadIdx.x;
   int y = blockIdx.y * blockDim.y + threadIdx.y;
   ```

4. **内存访问模式**：
   - 读取时：`input[y * width + x]`（行优先，合并访问）
   - 写入时：`output[y_t * height + x_t]`（列优先，但通过共享内存优化）

## 性能优化提示

1. **使用共享内存**：避免全局内存的非合并访问
2. **避免 Bank Conflict**：共享内存宽度设为 `TILE_SIZE + 1`
3. **合并访问**：确保相邻线程访问相邻内存地址
4. **调整 TILE_SIZE**：根据共享内存大小调整（通常 16×16 或 32×32）
