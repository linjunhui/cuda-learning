# 练习题目 05：C++ 类封装 CUDA 操作

## 题目描述

使用 C++ 类封装 CUDA 向量加法操作，实现一个可复用的 `VectorAdd` 类。

**功能要求**：
- 创建一个 `VectorAdd` 类，封装向量加法的所有操作
- 使用 RAII 原则管理内存（构造函数分配，析构函数释放）
- 提供简洁的接口进行向量加法
- 支持错误处理和资源管理

## 知识点

- C++ 类和对象
- RAII（Resource Acquisition Is Initialization）
- 构造函数和析构函数
- 拷贝构造函数和赋值运算符（或禁用）
- 异常处理
- CUDA 错误处理

### 步骤3：主程序（main.cu）

```cpp
#include "vector_add.h"
#include <cstdio>
#include <cstdlib>

int main() {
    const int n = 1000;
    
    // 主机端数据
    float *h_a = (float*)malloc(n * sizeof(float));
    float *h_b = (float*)malloc(n * sizeof(float));
    float *h_c = (float*)malloc(n * sizeof(float));
    
    // 初始化数据
    for (int i = 0; i < n; i++) {
        h_a[i] = 1.0f;
        h_b[i] = 2.0f;
    }
    
    // 创建 VectorAdd 对象（自动分配内存）
    VectorAdd adder(n);
    
    // 设置输入
    adder.setInputA(h_a);
    adder.setInputB(h_b);
    
    // 执行计算
    adder.compute();
    
    // 获取结果
    adder.getResult(h_c);
    
    // 验证结果
    bool correct = true;
    for (int i = 0; i < n; i++) {
        if (h_c[i] != 3.0f) {
            printf("Error at index %d: %f\n", i, h_c[i]);
            correct = false;
            break;
        }
    }
    
    if (correct) {
        printf("Vector addition completed successfully!\n");
    }
    
    // 清理主机内存
    free(h_a);
    free(h_b);
    free(h_c);
    
    // VectorAdd 析构函数自动释放设备内存
    
    return 0;
}
```

## 提示

1. **RAII 原则**：
   - 构造函数中分配资源
   - 析构函数中释放资源
   - 确保异常安全

2. **禁用拷贝**：
   ```cpp
   VectorAdd(const VectorAdd&) = delete;
   VectorAdd& operator=(const VectorAdd&) = delete;
   ```
   或者实现移动语义（C++11）

3. **错误处理**：
   ```cpp
   void checkCudaError(cudaError_t error, const char *file, int line) {
       if (error != cudaSuccess) {
           // 处理错误
       }
   }
   ```

4. **内存管理**：
   - 构造函数：`cudaMalloc`
   - 析构函数：`cudaFree`
   - 设置数据：`cudaMemcpy`
