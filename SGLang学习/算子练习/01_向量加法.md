# 练习题目 01：向量加法

## 题目描述

实现一个 CUDA 内核函数，将两个浮点数向量相加，结果存储在第三个向量中。

**功能要求**：
- 实现 `vectorAdd` 内核函数，计算 `c[i] = a[i] + b[i]`
- 在主机端分配和初始化内存
- 将数据从主机传输到设备
- 启动内核函数
- 将结果从设备传输回主机
- 验证结果正确性
- 释放所有内存

## 知识点

- CUDA 内核函数定义（`__global__`）
- 线程索引计算（`blockIdx.x`, `threadIdx.x`, `blockDim.x`）
- CUDA 内存管理（`cudaMalloc`, `cudaMemcpy`, `cudaFree`）
- 主机-设备数据传输
- 边界检查

## 提示

1. **线程索引计算**：
   ```cuda
   int idx = blockIdx.x * blockDim.x + threadIdx.x;
   ```

2. **边界检查**：
   ```cuda
   if (idx < n) {
       // 执行操作
   }
   ```

3. **网格大小计算**：
   ```cuda
   int blockSize = 256;
   int gridSize = (n + blockSize - 1) / blockSize;  // 向上取整
   ```

4. **内存传输方向**：
   - `cudaMemcpyHostToDevice`: 主机 → 设备
   - `cudaMemcpyDeviceToHost`: 设备 → 主机

## 测试用例

### 测试1：基本功能
- 输入：`n = 1000`, `a[i] = 1.0f`, `b[i] = 2.0f`
- 期望输出：`c[i] = 3.0f` 对所有 `i`

### 测试2：边界情况
- 输入：`n = 1`
- 期望输出：`c[0] = 3.0f`

### 测试3：大数组
- 输入：`n = 1000000`
- 期望输出：所有元素都是 `3.0f`
