# 练习题目 02：数组元素平方

## 题目描述

实现一个 CUDA 内核函数，计算数组中每个元素的平方，结果存储在另一个数组中。

**功能要求**：
- 实现 `squareElements` 内核函数，计算 `output[i] = input[i] * input[i]`
- 支持任意大小的数组
- 正确处理边界情况
- 完整的错误检查

## 知识点

- CUDA 内核函数
- 线程索引和边界检查
- CUDA 错误处理
- 内存管理最佳实践
