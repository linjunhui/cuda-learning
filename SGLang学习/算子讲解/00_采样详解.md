# 采样详解：大模型推理的采样机制

## 📖 为什么需要采样？

### 1. 大模型推理的本质

**大语言模型的输出过程**：
1. 模型前向传播得到 **logits**（原始分数）
2. Logits 经过 **softmax** 转换为概率分布
3. 从概率分布中**采样**得到下一个 token

**为什么不能直接选最高概率的 token？**

如果每次都选择概率最高的 token（**贪婪解码/Greedy Decoding**），会导致：
- ❌ **输出过于确定**：每次生成的结果都相同
- ❌ **缺乏创造性**：无法产生多样化的文本
- ❌ **容易陷入循环**：模型可能重复生成相同的模式
- ❌ **不符合自然语言特性**：自然语言本身就具有不确定性

### 2. 采样的作用

**采样（Sampling）** 通过引入随机性，使得模型输出更加：
- ✅ **多样化**：相同输入可能产生不同输出
- ✅ **创造性**：可以生成新颖的内容
- ✅ **自然**：更接近人类的语言表达方式
- ✅ **可控**：通过参数调整生成的随机性程度

## 🧠 采样原理

### 核心流程

```
Logits → Temperature缩放 → Softmax → 概率过滤 → 随机采样 → Token ID
```

### 详细步骤解析

#### 步骤 1：模型输出 Logits

**Logits** 是模型最后一层的原始输出，形状为 `[batch_size, vocab_size]`，表示每个 token 的原始分数。

```python
# 模型输出示例（假设词汇表大小=50000）
logits = tensor([
    [2.5, -1.2, 0.8, 3.1, ...],  # 第一个序列的 logits
    [1.9, 0.3, -0.5, 2.8, ...],  # 第二个序列的 logits
])
```

#### 步骤 2：Temperature 缩放

**Temperature（温度）** 控制分布的锐度：

```
scaled_logits = logits / temperature
```

**Temperature 的作用**：
- **Temperature = 1.0**：保持原始分布（默认）
- **Temperature > 1.0**：**提高随机性**，分布更平坦，输出更多样
- **Temperature < 1.0**：**降低随机性**，分布更尖锐，输出更确定
- **Temperature ≈ 0**：接近贪婪解码（总是选最高概率）

**数学原理**：
- Temperature 越大，softmax 后的概率分布越均匀
- Temperature 越小，概率高的 token 与概率低的 token 差距越大

**代码实现**：
```python
# SGLang 中的实现
logits.div_(sampling_info.temperatures)  # 除以 temperature
```

#### 步骤 3：Softmax 转换为概率

将缩放后的 logits 转换为概率分布：

```
probs = softmax(scaled_logits)
```

**Softmax 公式**：
```
P(token_i) = exp(logit_i / T) / Σ exp(logit_j / T)
```

其中 `T` 是 temperature。

**代码实现**：
```python
# SGLang 中的实现（见 sampler.py:122）
logits[:] = torch.softmax(logits, dim=-1)
probs = logits
```

#### 步骤 4：概率过滤（可选）

在采样之前，可以使用以下方法过滤概率分布：

##### 4.1 Top-k 采样

**原理**：只保留概率最高的 k 个 token，其余设为 0，然后重新归一化。

**作用**：
- 排除低概率的"噪声" token
- 只从最有希望的候选中采样
- 提高生成质量

**代码实现**：
```python
# SGLang 中的实现（见 sampling.py:top_k_renorm_probs）
# 保留 top-k，其余设为 0，然后归一化
probs_sort, probs_idx = probs.sort(dim=-1, descending=True)
probs_sort[..., k:] = 0.0  # 只保留前 k 个
probs = probs_sort / probs_sort.sum(dim=-1, keepdim=True)
```

**示例**：
```
原始概率: [0.4, 0.3, 0.15, 0.1, 0.05]
Top-k=3:  [0.471, 0.353, 0.176, 0, 0]  # 归一化后
```

##### 4.2 Top-p（Nucleus）采样

**原理**：从概率最高的 token 开始，累积概率直到达到阈值 `p`，只保留这些 token。

**作用**：
- 动态调整候选数量（不固定 k）
- 在概率集中时选择少数 token，在概率分散时选择更多 token
- 更灵活的控制策略

**代码实现**：
```python
# SGLang 中的实现（见 sampling.py:top_p_renorm_probs）
probs_sort, probs_idx = probs.sort(dim=-1, descending=True)
probs_sum = torch.cumsum(probs_sort, dim=-1)
# 找到累积概率超过 top_p 的最后一个位置
mask = probs_sum <= top_p
probs_sort[~mask] = 0.0
probs = probs_sort / probs_sort.sum(dim=-1, keepdim=True)
```

**示例**：
```
排序后概率: [0.4, 0.3, 0.15, 0.1, 0.05]
累积概率:   [0.4, 0.7, 0.85, 0.95, 1.0]
Top-p=0.8: [0.471, 0.353, 0.176, 0, 0]  # 累积到 0.85 > 0.8
```

##### 4.3 Min-p 采样

**原理**：只保留概率大于 `min_p * max_prob` 的 token。

**作用**：
- 相对阈值，相对于最高概率的比例
- 更稳定的过滤策略

**代码实现**：
```python
# SGLang 中的实现（见 sampling.py:min_p_sampling_from_probs）
max_probs = probs.max(dim=-1, keepdim=True)[0]
min_p_threshold = max_probs * min_p
mask = probs >= min_p_threshold
probs[~mask] = 0.0
probs = probs / probs.sum(dim=-1, keepdim=True)
```

**示例**：
```
原始概率: [0.4, 0.3, 0.15, 0.1, 0.05]
Max prob: 0.4
Min-p=0.3: [0.4, 0.3, 0.15, 0, 0]  # 0.3*0.4=0.12 作为阈值
归一化后: [0.471, 0.353, 0.176, 0, 0]
```

#### 步骤 5：随机采样

从过滤后的概率分布中随机采样一个 token：

**方法 1：Multinomial 采样**（标准方法）

```python
# PyTorch 的实现
token_id = torch.multinomial(probs, num_samples=1)
```

**原理**：根据概率分布进行加权随机采样，概率高的 token 被选中的几率更大。

**方法 2：确定性采样**（使用种子）

```python
# SGLang 中的实现（见 sampler.py:multinomial_with_seed）
# 使用 Gumbel-Max Trick 实现确定性采样
gumbel_noise = -log(-log(uniform_random))
perturbed_log_probs = log(probs) + gumbel_noise
token_id = argmax(perturbed_log_probs)
```

**原理**：
- 使用哈希函数从 seed 生成伪随机数
- 通过 Gumbel-Max Trick 实现确定性采样
- 相同 seed 产生相同结果（用于可复现性）

#### 步骤 6：GPU 优化实现

**SGLang 使用 FlashInfer 的融合 CUDA Kernel**：

```python
# 见 sampling.py:top_k_top_p_sampling_from_probs
# 融合的 GPU kernel，在一个 kernel 中完成：
# 1. Top-k 过滤
# 2. Top-p 过滤
# 3. Min-p 过滤
# 4. 随机采样
batch_next_token_ids = top_k_top_p_sampling_from_probs(
    probs,
    top_k,
    top_p,
    filter_apply_order="joint",  # 或 "top_k_first"
)
```

**优势**：
- **单 Kernel 融合**：减少内存访问和 kernel 启动开销
- **拒绝采样**：不需要显式排序，使用 GPU 并行拒绝采样
- **高效**：比多次 kernel 调用快得多

## 📋 采样参数详解

### 核心参数

#### 1. Temperature（温度）

**类型**：`float`  
**默认值**：`1.0`  
**范围**：`≥ 0.0`

**作用**：控制采样的随机性

**取值建议**：
- **0.0-0.3**：非常确定，接近贪婪解码
- **0.7-1.0**：平衡创造性和准确性（推荐用于大多数任务）
- **1.0-1.5**：更随机，更有创造性
- **> 1.5**：非常随机，可能产生无意义输出

**代码位置**：
```python
# sampling_params.py:41
temperature: float = 1.0

# sampler.py:117
logits.div_(sampling_info.temperatures)  # 除以 temperature
```

**特殊情况**：
```python
# 当 temperature ≈ 0 时，自动转换为贪婪解码
if 0 <= self.temperature < _SAMPLING_EPS:
    self.temperature = 1.0
    self.top_k = 1  # 贪婪采样
```

#### 2. Top-k

**类型**：`int`  
**默认值**：`-1`（禁用，等于全词汇表）  
**范围**：`≥ 1` 或 `-1`（禁用）

**作用**：只从概率最高的 k 个 token 中采样

**取值建议**：
- **1**：贪婪解码（总是选最高概率）
- **10-50**：限制在最有希望的候选中（推荐用于创意写作）
- **100-500**：允许更多多样性（推荐用于对话）
- **-1**：不限制（使用全部词汇表，罕见）

**代码位置**：
```python
# sampling_params.py:43
top_k: int = -1

# sampling.py:top_k_renorm_probs
# 保留 top-k，其余设为 0，归一化
```

#### 3. Top-p（Nucleus Sampling）

**类型**：`float`  
**默认值**：`1.0`  
**范围**：`(0.0, 1.0]`

**作用**：累积概率阈值，动态选择候选数量

**取值建议**：
- **0.1-0.3**：非常严格，只选最确定的 token
- **0.5-0.9**：平衡（推荐用于大多数任务）
- **0.95-1.0**：几乎不限制（默认 1.0）

**代码位置**：
```python
# sampling_params.py:42
top_p: float = 1.0

# sampling.py:top_p_renorm_probs
# 累积概率，找到超过 top_p 的位置
```

**Top-k vs Top-p**：
- **Top-k**：固定候选数量
- **Top-p**：动态候选数量（根据概率分布自适应）
- **通常同时使用**：先用 top-k 粗筛，再用 top-p 精筛

#### 4. Min-p

**类型**：`float`  
**默认值**：`0.0`  
**范围**：`[0.0, 1.0]`

**作用**：相对概率阈值，过滤低概率 token

**取值建议**：
- **0.0**：不限制（默认）
- **0.05-0.1**：轻度过滤
- **0.1-0.2**：中度过滤（推荐）
- **> 0.2**：严格过滤

**代码位置**：
```python
# sampling_params.py:44
min_p: float = 0.0

# sampling.py:min_p_sampling_from_probs
# 只保留概率 > min_p * max_prob 的 token
```

### 惩罚参数

#### 5. Frequency Penalty（频率惩罚）

**类型**：`float`  
**默认值**：`0.0`  
**范围**：`[-2.0, 2.0]`

**作用**：根据 token 的出现频率进行惩罚

**原理**：
```
penalty = frequency_penalty * token_frequency
logits[token] -= penalty
```

**取值建议**：
- **< 0**：鼓励重复（不推荐）
- **0.0**：不惩罚（默认）
- **0.1-0.5**：轻度惩罚重复（推荐用于长文本）
- **> 0.5**：强烈惩罚重复

**代码位置**：
```python
# sampling_params.py:45
frequency_penalty: float = 0.0
```

#### 6. Presence Penalty（存在惩罚）

**类型**：`float`  
**默认值**：`0.0`  
**范围**：`[-2.0, 2.0]`

**作用**：对出现过的 token 进行惩罚（不考虑频率，只看是否出现过）

**原理**：
```
if token in generated_tokens:
    logits[token] -= presence_penalty
```

**取值建议**：
- **0.0**：不惩罚（默认）
- **0.1-0.5**：轻度惩罚已出现的 token
- **> 0.5**：强烈避免重复

**代码位置**：
```python
# sampling_params.py:46
presence_penalty: float = 0.0
```

**Frequency Penalty vs Presence Penalty**：
- **Frequency Penalty**：惩罚强度随出现次数线性增长
- **Presence Penalty**：只要出现过就惩罚（常数）

#### 7. Repetition Penalty（重复惩罚）

**类型**：`float`  
**默认值**：`1.0`  
**范围**：`[0.0, 2.0]`

**作用**：对已生成 token 的 logits 进行缩放

**原理**：
```
if token in generated_tokens:
    logits[token] *= (1.0 / repetition_penalty)
```

**取值建议**：
- **< 1.0**：鼓励重复（不推荐）
- **1.0**：不惩罚（默认）
- **1.1-1.3**：轻度惩罚（推荐）
- **> 1.3**：强烈避免重复

**代码位置**：
```python
# sampling_params.py:47
repetition_penalty: float = 1.0
```

### 其他参数

#### 8. Sampling Seed（采样种子）

**类型**：`int`  
**默认值**：`42`

**作用**：控制随机数生成，实现确定性采样

**用途**：
- **可复现性**：相同 seed 产生相同结果
- **调试**：固定结果便于调试
- **实验对比**：控制变量对比不同参数

#### 9. Logit Bias（Logit 偏置）

**类型**：`Dict[str, float]`  
**默认值**：`None`

**作用**：对特定 token 的 logits 进行偏移

**用法**：

## 🔄 采样流程总结

### SGLang 中的完整采样流程

```python
# 1. 模型输出 logits
logits = model_output.next_token_logits  # [batch_size, vocab_size]

# 2. 预处理 logits（自定义处理器、NaN 处理）
logits = self._preprocess_logits(logits, sampling_info)

# 3. 判断是否全部使用贪婪采样
if sampling_info.is_all_greedy:
    next_token_ids = torch.argmax(logits, -1)
else:
    # 4. 应用 temperature 缩放
    logits.div_(sampling_info.temperatures)
    
    # 5. Softmax 转换为概率
    probs = torch.softmax(logits, dim=-1)
    
    # 6. 判断是否需要过滤
    if need_filtering:
        # 7. 应用 top-k, top-p, min-p 过滤
        if sampling_backend == "flashinfer":
            # 使用融合 GPU kernel
            next_token_ids = top_k_top_p_sampling_from_probs(
                probs,
                top_k,
                top_p,
                filter_apply_order="joint",
            )
        else:
            # 使用 PyTorch 实现
            next_token_ids = top_k_top_p_min_p_sampling_from_probs_torch(...)
    else:
        # 8. 直接采样（无过滤）
        next_token_ids = sampling_from_probs_torch(probs)

# 9. 返回采样的 token IDs
return next_token_ids
```

## 💡 总结

### 采样的重要性

采样是大模型推理中的**关键环节**，它：
1. **平衡确定性和随机性**：通过 temperature 控制
2. **提高输出质量**：通过 top-k/top-p 过滤低质量候选
3. **增强创造性**：引入随机性产生多样化输出
4. **防止重复**：通过各种惩罚机制

### 参数调优建议

- **从默认值开始**：`temperature=1.0, top_p=1.0, top_k=-1`
- **根据任务调整**：创意任务提高 temperature，事实任务降低 temperature
- **逐步微调**：一次调整一个参数，观察效果
- **组合使用**：top-k 和 top-p 通常配合使用效果更好

### 性能优化

SGLang 通过以下方式优化采样性能：
- ✅ **融合 CUDA Kernel**：将多个操作合并到一个 kernel
- ✅ **GPU 并行拒绝采样**：不需要显式排序
- ✅ **批处理优化**：支持不同请求使用不同参数
