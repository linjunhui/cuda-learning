## 概述

SGLang 的模型加载系统是一个高度模块化和可扩展的框架，支持多种模型格式、量化方法和加载策略。它通过统一的接口 `get_model()` 来加载模型，内部根据配置自动选择合适的加载器。

### 核心设计理念

1. **模块化设计**: 通过不同的 `ModelLoader` 类支持不同的加载策略
2. **格式自动检测**: 默认使用 `AUTO` 格式，自动选择最优的加载方式
3. **量化集成**: 原生支持多种量化方法（FP8、INT8、AWQ、GPTQ等）
4. **内存优化**: 支持分层加载、CPU卸载等内存优化策略
5. **分布式支持**: 支持张量并行、流水线并行等分布式加载

## 核心组件

### 1. ModelConfig

`ModelConfig` 定义了模型的基本配置信息，位于 `sglang/srt/configs/model_config.py`。

#### 主要参数

```python
class ModelConfig:
    def __init__(
        self,
        model_path: str,                    # 模型路径（本地路径或HuggingFace模型ID）
        trust_remote_code: bool = True,     # 是否信任远程代码
        revision: Optional[str] = None,      # 模型版本/分支
        context_length: Optional[int] = None, # 上下文长度
        model_override_args: str = "{}",    # 模型配置覆盖参数（JSON字符串）
        is_embedding: Optional[bool] = None, # 是否为嵌入模型
        enable_multimodal: Optional[bool] = None, # 是否启用多模态
        dtype: str = "auto",                # 数据类型（auto/float16/bfloat16/float32）
        quantization: Optional[str] = None,  # 量化方法
        override_config_file: Optional[str] = None, # 覆盖配置文件路径
        is_draft_model: bool = False,       # 是否为草稿模型（用于推测解码）
        hybrid_kvcache_ratio: Optional[float] = None, # 混合KV缓存比例
        model_impl: Union[str, ModelImpl] = ModelImpl.AUTO, # 模型实现方式
        sampling_defaults: str = "openai",  # 采样默认配置
        quantize_and_serve: bool = False,   # 是否量化并服务
    )
```

#### 关键属性

- `model_path`: 模型路径，可以是本地路径或 HuggingFace 模型ID（如 `meta-llama/Llama-2-7b-hf`）
- `dtype`: 模型数据类型，`"auto"` 会根据模型配置自动选择
- `quantization`: 量化方法，如 `"fp8"`, `"awq"`, `"gptq"`, `"modelopt_fp8"` 等
- `hf_config`: HuggingFace 的模型配置对象（`PretrainedConfig`）
- `hf_text_config`: 文本模型的配置（对于多模态模型，提取文本部分）
- `is_multimodal`: 是否为多模态模型
- `is_encoder_decoder`: 是否为编码器-解码器架构

## 模型加载流程

### 入口函数

模型加载的入口函数是 `get_model()`，位于 `sglang/srt/model_loader/__init__.py`:

```python
def get_model(
    *,
    model_config: ModelConfig,
    load_config: LoadConfig,
    device_config: DeviceConfig,
) -> nn.Module:
    loader = get_model_loader(load_config, model_config)
    return loader.load_model(
        model_config=model_config,
        device_config=device_config,
    )
```

### 完整加载流程

1. **获取加载器**: 根据 `LoadConfig` 和 `ModelConfig` 选择合适的 `ModelLoader`
2. **初始化模型架构**: 根据模型配置识别架构并创建模型类
3. **准备权重**: 从磁盘或远程下载模型权重文件
4. **加载权重**: 将权重加载到模型中
5. **后处理**: 应用量化、设备迁移等后处理操作
6. **设置为评估模式**: 调用 `model.eval()`

### 详细流程说明

#### 步骤1: 获取加载器

`get_model_loader()` 函数根据配置选择合适的加载器：

```python
def get_model_loader(
    load_config: LoadConfig, 
    model_config: Optional[ModelConfig] = None
) -> BaseModelLoader:
    # 1. 检查是否为DUMMY格式
    if load_config.load_format == LoadFormat.DUMMY:
        return DummyModelLoader(load_config)
    
    # 2. 检查ModelOpt量化
    if model_config and model_config.quantization in ["modelopt_fp8", "modelopt_fp4", "modelopt"]:
        return ModelOptModelLoader(load_config)
    
    # 3. 根据load_format选择加载器
    if load_config.load_format == LoadFormat.SHARDED_STATE:
        return ShardedStateLoader(load_config)
    elif load_config.load_format == LoadFormat.BITSANDBYTES:
        return BitsAndBytesModelLoader(load_config)
    elif load_config.load_format == LoadFormat.GGUF:
        return GGUFModelLoader(load_config)
    elif load_config.load_format == LoadFormat.LAYERED:
        return LayeredModelLoader(load_config)
    elif load_config.load_format == LoadFormat.REMOTE:
        return RemoteModelLoader(load_config)
    elif load_config.load_format == LoadFormat.REMOTE_INSTANCE:
        return RemoteInstanceModelLoader(load_config)
    
    # 4. 默认加载器
    return DefaultModelLoader(load_config)
```

#### 步骤2: 初始化模型

`_initialize_model()` 函数负责创建模型实例：

```python
def _initialize_model(
    model_config: ModelConfig,
    load_config: LoadConfig,
) -> nn.Module:
    # 1. 获取模型架构类
    model_class, _ = get_model_architecture(model_config)
    
    # 2. 获取量化配置
    quant_config = _get_quantization_config(
        model_config, load_config, packed_modules_mapping, remap_prefix
    )
    
    # 3. 构建初始化参数
    kwargs = {
        "config": model_config.hf_config,
        "quant_config": quant_config,
    }
    
    # 4. 创建模型实例
    return model_class(**kwargs)
```

#### 步骤3: 加载权重

`DefaultModelLoader.load_model()` 的核心逻辑：

```python
def load_model(
    self,
    *,
    model_config: ModelConfig,
    device_config: DeviceConfig,
) -> nn.Module:
    target_device = torch.device(device_config.device)
    
    # 1. 设置默认数据类型
    with set_default_torch_dtype(model_config.dtype):
        with target_device:
            # 2. 初始化模型（空权重）
            model = _initialize_model(model_config, self.load_config)
        
        # 3. 加载权重并后处理
        self.load_weights_and_postprocess(
            model, 
            self._get_all_weights(model_config, model), 
            target_device
        )
    
    # 4. 设置为评估模式
    return model.eval()
```

## 加载器类型

### 1. DefaultModelLoader

默认加载器，支持最常见的加载场景。

**特点**:
- 支持 SafeTensors 和 PyTorch 格式
- 自动检测最优格式
- 支持多线程加载
- 支持权重解密

**使用场景**:
- 标准的 HuggingFace 模型
- 本地模型文件
- 需要快速加载的场景

### 2. LayeredModelLoader

分层加载器，逐层加载模型以降低峰值内存。

**特点**:
- 逐层加载权重
- 每层加载后立即量化（如果启用）
- 显著降低峰值内存占用
- 需要模型支持 `load_weights_to_module()` 方法

**使用场景**:
- 内存受限的环境
- 需要在线量化的场景
- 大模型加载

**实现原理**:
```python
def load_model(self, model_config, device_config):
    # 1. 在meta设备上创建模型（不分配实际内存）
    with torch.device("meta"):
        model = _initialize_model(model_config, self.load_config)
    
    # 2. 获取所有权重
    weights = self._get_all_weights(model_config, model)
    
    # 3. 递归填充每个模块
    def fill_module(module, fqn, weights):
        # 先处理子模块
        for name, submod in module.named_children():
            fill_module(submod, fqn + [name], weights)
        
        # 在目标设备上创建空张量
        module.to_empty(device=target_device, recurse=False)
        
        # 加载该模块的权重
        model.load_weights_to_module(module, fqn, weights)
        
        # 应用量化（如果启用）
        if quant_method:
            quant_method.process_weights_after_loading(module)
```

### 3. ModelOptModelLoader

ModelOpt 量化加载器，支持 NVIDIA ModelOpt 量化工具。

**特点**:
- 支持 FP8、FP4 量化
- 支持量化校准
- 支持预量化模型加载
- 支持量化检查点保存/恢复

**使用场景**:
- 使用 ModelOpt 量化的模型
- 需要在线量化的场景
- 追求极致性能的场景

### 4. GGUFModelLoader

GGUF 格式加载器，兼容 llama.cpp 的模型格式。

**特点**:
- 支持 GGUF 格式
- 支持多种量化类型（Q4_0, Q4_1, Q5_0, Q5_1, Q8_0等）
- 高效的内存映射加载

**使用场景**:
- 从 llama.cpp 转换的模型
- 需要兼容 llama.cpp 的场景

### 5. BitsAndBytesModelLoader

BitsAndBytes 量化加载器，支持 NF4 等量化格式。

**特点**:
- 支持 BitsAndBytes 量化
- 支持 4-bit 量化（NF4）
- 支持 8-bit 量化

**使用场景**:
- 使用 BitsAndBytes 量化的模型
- 需要低精度推理的场景

### 6. RemoteModelLoader / RemoteInstanceModelLoader

远程加载器，支持从远程服务器加载模型。

**特点**:
- 支持远程模型加载
- 支持分布式权重传输
- 支持 RDMA 加速

**使用场景**:
- 模型存储在远程服务器
- 分布式推理场景
- 共享模型存储的场景

### 7. DummyModelLoader

虚拟加载器，用于性能分析和测试。

**特点**:
- 不加载实际权重
- 使用随机初始化
- 快速启动

**使用场景**:
- 性能分析
- 功能测试
- 不需要实际权重的场景

## 支持的加载格式

### 1. AUTO（自动）

**行为**:
1. 优先尝试加载 `.safetensors` 文件
2. 如果不存在，回退到 `.bin` (PyTorch) 文件
3. 自动下载缺失的文件

**优势**:
- 无需手动指定格式
- SafeTensors 更安全且加载更快
- 自动回退保证兼容性

### 2. SafeTensors

**特点**:
- 更安全的格式（防止任意代码执行）
- 更快的加载速度
- 支持内存映射
- 支持多线程加载

**文件格式**:
- `model.safetensors` (单文件)
- `model.safetensors.index.json` + 多个分片文件 (多文件)

### 3. PyTorch (.pt / .bin)

**特点**:
- 标准 PyTorch 格式
- 广泛兼容
- 支持 `torch.load()` 直接加载

**文件格式**:
- `pytorch_model.bin` (单文件)
- `pytorch_model-*.bin` (多文件分片)

### 4. NumPy Cache (npcache)

**特点**:
- 将 PyTorch 权重转换为 NumPy 格式并缓存
- 显著加速后续加载
- 首次加载需要转换时间

**工作流程**:
1. 首次加载：读取 `.bin` 文件，转换为 NumPy 格式，保存为 `.npy` 缓存
2. 后续加载：直接读取 `.npy` 缓存文件

### 5. GGUF

**特点**:
- llama.cpp 兼容格式
- 支持多种量化类型
- 高效的内存映射

**量化类型**:
- Q4_0, Q4_1: 4-bit 量化
- Q5_0, Q5_1: 5-bit 量化
- Q8_0: 8-bit 量化
- F16, F32: 浮点格式

## 量化支持

SGLang 支持多种量化方法，通过 `ModelConfig.quantization` 参数指定。

### 支持的量化方法

1. **FP8**: 8-bit 浮点量化（需要 H100/A100 等支持 FP8 的 GPU）
2. **AWQ**: Activation-aware Weight Quantization
3. **GPTQ**: GPT Quantization
4. **SmoothQuant**: 平滑量化
5. **ModelOpt FP8/FP4**: NVIDIA ModelOpt 量化
6. **BitsAndBytes**: NF4, INT8 等

### 量化配置流程

```python
def _get_quantization_config(
    model_config: ModelConfig,
    load_config: LoadConfig,
    packed_modules_mapping: Dict[str, List[str]],
    remap_prefix: Dict[str, str] | None = None,
) -> Optional[QuantizationConfig]:
    if model_config.quantization is not None:
        # 1. 获取量化配置
        quant_config = get_quant_config(
            model_config, load_config, packed_modules_mapping, remap_prefix
        )
        
        # 2. 检查GPU能力
        capability = get_device_capability()
        if capability < quant_config.get_min_capability():
            raise ValueError(f"GPU不支持该量化方法")
        
        # 3. 检查数据类型兼容性
        supported_dtypes = quant_config.get_supported_act_dtypes()
        if model_config.dtype not in supported_dtypes:
            raise ValueError(f"数据类型不兼容")
        
        return quant_config
    return None
```

### 量化后处理

权重加载后，量化方法可能需要后处理：

```python
def load_weights_and_postprocess(model, weights, target_device):
    # 1. 加载权重
    model.load_weights(weights)
    
    # 2. 对每个模块应用量化后处理
    for _, module in model.named_modules():
        quant_method = getattr(module, "quant_method", None)
        if quant_method is not None:
            # 在目标设备上处理权重（重新打包、量化等）
            with device_loading_context(module, target_device):
                quant_method.process_weights_after_loading(module)
```

def get_model_architecture(model_config: ModelConfig):

### 模型注册表

模型注册表位于 `sglang/srt/models/registry.py`，通过动态导入模型类：

```python
@lru_cache()
def import_model_classes(package_name: str):
    model_arch_name_to_cls = {}
    package = importlib.import_module(package_name)
    
    # 遍历包中的所有模块
    for _, name, ispkg in pkgutil.iter_modules(package.__path__, package_name + "."):
        if not ispkg:
            module = importlib.import_module(name)
            
            # 查找EntryClass（模型入口类）
            if hasattr(module, "EntryClass"):
                entry = module.EntryClass
                if isinstance(entry, list):
                    # 支持一个模块多个模型类
                    for tmp in entry:
                        model_arch_name_to_cls[tmp.__name__] = tmp
                else:
                    model_arch_name_to_cls[entry.__name__] = entry
    
    return model_arch_name_to_cls
```

## 权重加载机制

### 权重迭代器

SGLang 使用迭代器模式加载权重，支持流式加载以节省内存。

#### SafeTensors 迭代器

```python
def safetensors_weights_iterator(
    hf_weights_files: List[str],
    disable_mmap: bool = False
) -> Generator[Tuple[str, torch.Tensor], None, None]:
    for file_path in hf_weights_files:
        with safe_open(file_path, framework="pt", device="cpu") as f:
            for key in f.keys():
                tensor = f.get_tensor(key)
                yield key, tensor
```

#### 多线程加载

```python
def multi_thread_safetensors_weights_iterator(
    hf_weights_files: List[str],
    max_workers: int = 8,
    disable_mmap: bool = False
) -> Generator[Tuple[str, torch.Tensor], None, None]:
    with ThreadPoolExecutor(max_workers=max_workers) as executor:
        futures = []
        for file_path in hf_weights_files:
            future = executor.submit(load_safetensors_file, file_path)
            futures.append(future)
        
        for future in as_completed(futures):
            for key, tensor in future.result():
                yield key, tensor
```

## 内存管理

### 设备上下文管理

SGLang 使用上下文管理器来管理权重的设备位置：

```python
@contextmanager
def device_loading_context(module: torch.nn.Module, target_device: torch.device):
    # 1. 将CPU上的参数临时移动到目标设备
    original_infos = {}
    for name, p in module.named_parameters():
        if p.device.type == "cpu":
            original_data = p.data
            device_data = p.data.to(target_device)
            original_infos[name] = {
                "device": p.device,
                "original_data": original_data,
                "device_data": device_data,
            }
            p.data = device_data
    
    try:
        yield module
    finally:
        # 2. 恢复参数到原始设备
        for name, p in module.named_modules():
            if name in original_infos:
                # 将数据复制回CPU
                original_data.copy_(p.data.to(original_data.device))
                p.data = original_data
```

### CPU 卸载

对于内存受限的场景，SGLang 支持 CPU 卸载（CPU Offloading）：

- 权重存储在 CPU 内存
- 推理时临时加载到 GPU
- 推理完成后释放 GPU 内存

### 内存优化策略

1. **分层加载**: 逐层加载，降低峰值内存
2. **内存映射**: 使用 `mmap` 避免重复加载
3. **延迟加载**: 仅在需要时加载权重
4. **量化**: 降低权重精度，减少内存占用

```python
class ModelRunner:
    def load_model(self):
        # 在内存管理区域中加载模型
        with self.memory_saver_adapter.region(
            GPU_MEMORY_TYPE_WEIGHTS,
            enable_cpu_backup=enable_cpu_backup,
        ):
            self.model = get_model(
                model_config=self.model_config,
                load_config=self.load_config,
                device_config=DeviceConfig(self.device, self.gpu_id),
            )
        
        # 后处理
        get_offloader().post_init()
        
        # 加载KV缓存缩放因子（如果使用FP8 KV缓存）
        if self.server_args.kv_cache_dtype == "fp8_e4m3":
            if self.server_args.quantization_param_path:
                self.model.load_kv_cache_scales(
                    self.server_args.quantization_param_path
                )
```
