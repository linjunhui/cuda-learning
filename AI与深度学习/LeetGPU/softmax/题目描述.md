# Softmax

**难度：** 中等

-----

## 题目描述

编写一个程序，在 **GPU** 上计算一个包含 32 位浮点数数组的 **Softmax 函数**。

### Softmax 函数定义

对于一个长度为 $N$ 的输入数组 $x$，其 Softmax（记作 $\sigma(x)$）是一个长度为 $N$ 的数组，其中第 $i$ 个元素的定义为：

$$\sigma (x)_i = \frac{e^{x_i}}{\sum_{j=1}^{N} e^{x_j}}$$

### 溢出处理要求 (Max Trick)

你的解决方案必须通过使用 "**最大值技巧**"（**max trick**）来处理潜在的溢出问题。具体来说，在进行指数运算 $e^{x_i}$ 之前，应先用输入数组中的**最大值**减去数组中的每个元素。

## 实现要求

1.  仅使用原生功能（不允许使用外部库）。
2.  `solve` 函数签名必须保持不变。
3.  最终结果必须存储在 `output` 数组中。

## 示例

### 示例 1

| 属性 | 值 |
| :--- | :--- |
| **输入 (Input):** | `[1.0, 2.0, 3.0]` |
| **N:** | 3 |
| **输出 (Output):** | `[0.090, 0.244, 0.665]` (近似值) |

### 示例 2

| 属性 | 值 |
| :--- | :--- |

| **N:** | 5 |
| **输出 (Output):** | `[2.04e-09, 4.52e-07, 9.99e-01, 2.26e-02, 9.77e-01]` (近似值) |

## 约束条件 (Constraints)

$$1 \le N \le 500,000$$
