# 向量加法开发计划

## 方案设计

### 核心功能
1. 基础向量加法：实现 `c[i] = a[i] + b[i]`
2. 错误检查：添加 CUDA 错误处理
3. 结果验证：自动验证计算结果正确性

### 扩展功能（可选）
1. 多种数据类型支持：使用模板支持 `float`、`double`、`int` 等
2. 性能测试：测量执行时间

## 项目规划

### 文件结构
```
01_向量加法/
├── src/
│   ├── vector_add.cuh # CUDA 内核函数声明（模板）
│   ├── vector_add.cu  # CUDA 内核函数实现
│   └── main.cpp       # 主程序入口
├── CMakeLists.txt     # CMake 配置文件（可选）
└── README.md          # 使用说明（可选）
```

### 文件职责

**vector_add.cuh**
- 声明 `vectorAdd` 内核函数（模板）
- 包含必要的 CUDA 头文件
- 如果使用模板，可以在这里提供模板实现

**vector_add.cu**
- 实现 `vectorAdd` 内核函数
- 实现主机端辅助函数（内存管理、错误检查）
- 如果使用模板，包含模板实现或显式实例化

**main.cpp**
- 初始化测试数据
- 调用向量加法函数
- 验证结果
- 输出测试结果

## 编译方式

### 方式1：直接使用 nvcc（推荐，简单）
```bash
cd src
nvcc -o vector_add vector_add.cu main.cpp
./vector_add
```

### 方式2：使用 CMake（可选）
```bash
# 创建构建目录
mkdir build && cd build

# 配置项目（Debug 模式）
cmake ..

# 或者 Release 模式
# cmake -DCMAKE_BUILD_TYPE=Release ..

# 编译
make

# 运行（可执行文件在 build/bin/ 目录）
./bin/vector_add

# 或者从 build 目录运行
cd bin && ./vector_add
```

**CMakeLists.txt 说明**：
- 已配置好 CUDA 支持
- 自动检测 CUDA 工具包
- 支持 Debug 和 Release 模式
- 如果编译出错，检查 CUDA 架构设置（第 41 行）

## 注意事项

1. **文件扩展名**：
   - `.cuh` 文件：CUDA 头文件，包含内核函数声明（模板函数）
   - `.cu` 文件：CUDA 源文件，包含内核函数实现
   - `.cpp` 文件：纯 C++ 代码（主机端）

2. **简单优先**：
   - 先完成基础功能，再考虑扩展
   - 保持代码简洁易懂

3. **测试驱动**：
   - 每完成一个功能立即测试
   - 确保所有测试用例通过
