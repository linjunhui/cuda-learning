## 2. 单元测试用例

### 2.1 FixedSizePool 基础
| 用例 | 描述 | 预期 |
|------|------|------|
| 构造 | 创建 FixedSizePool(64, 100) | 无异常 |
| allocate | 分配一块内存 | 非 nullptr，可写入 |
| deallocate | 释放后再次分配 | 可重复使用 |
| 耗尽 | 分配 block_count 次 | 第 block_count+1 次返回 nullptr |
| reset | 分配若干后 reset | 可再次分配 block_count 块 |

### 2.2 边界与异常
| 用例 | 描述 | 预期 |
|------|------|------|
| deallocate(nullptr) | 传空指针 | 不崩溃 |
| 多线程 | 多线程并发 alloc/dealloc | 无数据竞争、无泄漏 |

### 2.3 测试文件
- `tests/unit_tests/memory_pool/test_fixed_size_pool.cpp`
- `tests/unit_tests/memory_pool/test_block_header.cpp`（如有）
