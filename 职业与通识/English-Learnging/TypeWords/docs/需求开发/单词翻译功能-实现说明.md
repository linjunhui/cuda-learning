## 🎯 使用方法

1. **在文章学习界面**：
   - 当正在输入或选中一个单词时
   - 按下 `Ctrl + B` 快捷键
   - 弹窗会自动显示该单词的音标和中文意思

2. **快捷键说明**：
   - 快捷键：`Ctrl + B`
   - 可在设置页面查看和修改快捷键
   - 设置路径：设置 → 快捷键 → 单词翻译

## ⚠️ 注意事项

1. **API 限制**：
   - 金山词霸 API 可能有请求频率限制
   - 建议添加请求缓存机制（可选优化）

2. **网络依赖**：
   - 功能需要网络连接
   - 离线时无法获取翻译

3. **跨域问题**：
   - 如果遇到 CORS 问题，可能需要配置代理
   - 当前实现直接调用，如果浏览器阻止，需要后端代理

4. **单词获取**：
   - 当前实现获取的是正在输入的单词
   - 如果用户想翻译其他单词，需要先切换到该单词

## 🚀 后续优化建议
