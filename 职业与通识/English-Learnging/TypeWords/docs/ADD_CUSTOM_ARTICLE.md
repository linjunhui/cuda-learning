## 创建自定义书籍

在添加文章之前，需要先创建一个自定义书籍（词典）。

### 步骤

1. **进入文章列表页面**
   - 点击导航栏的"文章"或"书籍"选项
   - 进入书籍列表页面

2. **创建新书籍**
   - 点击"添加"或"创建"按钮（通常在页面右上角或底部）
   - 或访问书籍详情页面，点击"编辑"按钮后选择"创建"

3. **填写书籍信息**
   - **名称**：输入书籍名称（必填，最多20个字符）
   - **描述**：输入书籍描述（可选）
   - 点击"确定"保存

4. **开始添加文章**
   - 创建成功后，会自动进入书籍详情页面
   - 点击"文章管理"或"编辑"按钮开始添加文章

## 添加单篇文章

### 方法一：通过文章管理页面添加

1. **进入文章管理页面**
   - 在书籍详情页面，点击"文章管理"按钮
   - 或从书籍列表中选择书籍后进入详情页

2. **添加新文章**
   - 在文章管理页面，点击"新增"按钮
   - 左侧文章列表会显示"正在添加新文章..."

3. **编辑文章内容**

   **原文部分**：
   - **标题**：输入文章标题
   - **正文**：复制粘贴原文内容
     - 格式要求：一行一句，段落间空一行
     - 例如：
       ```
       Last week I went to the theatre.
       I had a very good seat.
       The play was very interesting.

       I did not enjoy it.
       ```
   - 点击"分句"按钮进行自动分句
   - 点击"应用"按钮同步到结果栏

   **译文部分**：
   - **标题**：输入翻译后的标题
   - **正文**：输入或粘贴译文
     - 格式要求：一行一句，段落间空一行
   - 如果没有译文，可以：
     - 点击"翻译"按钮使用百度翻译（需要配置翻译API）
     - 或手动输入译文
   - 点击"分句"按钮进行自动分句
   - 点击"应用"按钮同步到结果栏

4. **保存文章**
   - 检查结果栏中的分句是否正确
   - 可以点击任意句子进行编辑
   - 确认无误后，点击"保存"按钮
   - 如需继续添加，点击"保存并添加下一篇"

### 方法二：通过书籍详情页快速添加

1. 在书籍详情页面，点击"编辑"按钮
2. 在编辑模式下，可以直接添加文章
3. 按照上述步骤填写文章内容

## 批量导入文章

支持通过 Excel 文件批量导入文章，适合需要添加大量文章的场景。

### 准备 Excel 文件

Excel 文件需要包含以下列（列名必须完全匹配）：

| 列名 | 说明 | 必填 |
|------|------|------|
| 原文标题 | 文章的英文标题 | 是 |
| 原文正文 | 文章的英文正文 | 是 |
| 译文标题 | 文章的中文标题 | 否 |
| 译文正文 | 文章的中文译文 | 否 |
| 音频地址 | 音频文件的URL地址 | 否 |

### 导入步骤

1. **准备 Excel 文件**
   - 使用 Excel 或 WPS 创建文件
   - 第一行为列名（必须包含"原文标题"和"原文正文"）
   - 从第二行开始填写文章数据
   - 保存为 `.xlsx` 格式

2. **导入文件**
   - 进入文章管理页面
   - 点击"导入"按钮
   - 选择准备好的 Excel 文件
   - 等待导入完成

3. **处理重复文章**
   - 如果导入的文章标题与现有文章重复
   - 系统会提示是否覆盖
   - 选择"是"覆盖，选择"否"跳过重复文章

### Excel 文件示例

```
原文标题         | 原文正文                    | 译文标题     | 译文正文              | 音频地址
----------------|----------------------------|--------------|----------------------|----------
A Private Talk  | Last week I went...        | 私人谈话     | 上周我去...          | http://...
An Exciting Trip| I have just received...    | 激动人心的旅行| 我刚收到...          |
```

## 编辑文章

### 修改文章内容

1. **进入编辑模式**
   - 在文章管理页面，点击要编辑的文章
   - 或从书籍详情页选择文章后点击"编辑"

2. **修改内容**
   - 修改原文或译文后，点击"应用"按钮同步
   - 可以直接在结果栏中点击句子进行编辑
   - 修改后会自动同步到原文/译文区域

3. **保存修改**
   - 点击"保存"按钮保存更改

### 调整分句

如果自动分句不正确，可以手动调整：

1. 在原文或译文区域，按照格式要求修改
   - 一行一句
   - 段落间空一行
2. 点击"应用"按钮重新分句
3. 在结果栏中可以直接编辑单个句子

### 配置人名忽略

在练习时，可以配置需要忽略的人名：

1. 在编辑文章页面，点击"人名配置"按钮
2. 添加需要忽略的人名
3. 练习时这些名称会被自动忽略（默认开启）

## 文章管理

### 查看文章列表

- 在书籍详情页面左侧可以看到所有文章
- 点击文章标题可以查看文章内容
- 文章列表显示文章标题和译文标题

### 删除文章

1. 在文章管理页面
2. 选择要删除的文章
3. 点击删除按钮（通常在列表项右侧）
4. 确认删除

### 调整文章顺序

在文章管理页面，可以通过拖拽调整文章顺序。

### 收藏文章

- 在文章列表中，点击文章右侧的星标图标
- 收藏的文章会保存到"收藏"书籍中

## 导出文章

可以将文章导出为 Excel 文件，方便备份或分享。

### 导出单篇文章

1. 在文章管理页面，选择要导出的文章
2. 点击"导出"按钮
3. 选择"当前"选项
4. 文件会自动下载

### 导出所有文章

1. 在文章管理页面
2. 点击"导出"按钮
3. 选择"全部"选项
4. 文件会自动下载，文件名格式：`书籍名称.xlsx`

### 导出文件格式

导出的 Excel 文件包含以下列：
- 原文标题
- 原文正文
- 译文标题
- 译文正文
- 音频地址

## 音频配置

### 上传音频文件

1. **上传音频**
   - 在编辑文章页面，点击"音频管理"
   - 点击"上传音频"按钮
   - 选择音频文件（支持常见音频格式）

2. **上传 LRC 文件**（可选）
   - LRC 文件用于自动解析句子对应的音频时间位置
   - 点击"上传 LRC 文件"按钮
   - 选择 LRC 文件
   - 系统会自动匹配句子和音频时间轴

**注意**：
- 上传的文件保存在本地电脑上
- 更换电脑数据将丢失，请及时备份
- LRC 文件解析可能不准确，需要手动调整

### 手动设置音频时间轴

如果 LRC 文件解析不准确，可以手动设置：

1. **设置句子音频时间**
   - 在结果栏中，找到要设置的句子
   - 点击句子右侧的音频编辑图标
   - 在弹窗中播放音频

2. **记录开始时间**
   - 播放音频到句子开始时
   - 点击"记录"按钮（开始时间）
   - 或手动输入时间（秒）

3. **记录结束时间**
   - 播放音频到句子结束时
   - 点击"记录"按钮（结束时间）
   - 或点击"结束"按钮设置为音频结尾

4. **调整时间**
   - 可以使用 +/- 0.3秒 按钮微调
   - 可以使用前一句的结束时间作为当前句的开始时间
   - 点击"跳转"按钮可以跳转到指定时间点

5. **试听确认**
   - 设置完成后，点击播放按钮试听
   - 确认无误后点击"确定"保存

### 使用在线音频

如果文章有在线音频地址，可以直接在"音频地址"字段填入 URL。

## 常见问题

### Q: 分句不正确怎么办？

**A**: 
1. 检查原文格式是否符合要求（一行一句，段落间空一行）
2. 手动调整格式后点击"应用"重新分句
3. 在结果栏中可以直接编辑单个句子

### Q: 翻译功能无法使用？

**A**: 
- 翻译功能需要配置百度翻译 API
- 如果没有配置，可以手动输入译文
- 或使用其他翻译工具翻译后复制粘贴

### Q: 导入的 Excel 文件格式不对？

**A**: 
- 确保第一行是列名
- 列名必须包含"原文标题"和"原文正文"
- 列名必须完全匹配（区分大小写）
- 文件格式必须是 `.xlsx`

### Q: 音频文件上传后找不到？

**A**: 
- 音频文件保存在本地浏览器中
- 更换电脑或清除浏览器数据会丢失
- 建议使用在线音频地址或定期备份数据

### Q: 如何备份文章数据？

**A**: 
1. 使用导出功能导出 Excel 文件
2. 保存 Excel 文件到安全位置
3. 需要时可以重新导入

### Q: 文章顺序可以调整吗？

**A**: 
- 可以在文章管理页面通过拖拽调整顺序
- 调整后会自动保存

### Q: 可以删除书籍吗？

**A**: 
- 自定义书籍可以删除
- 系统内置书籍不能删除，但可以重置为默认状态

### Q: 文章可以分享给其他人吗？

**A**: 
- 可以导出 Excel 文件分享
- 接收者可以导入到自己的账户中

## 使用技巧

1. **批量添加文章**
   - 优先使用 Excel 导入功能
   - 可以一次性导入多篇文章

2. **提高分句准确性**
   - 确保原文格式规范
   - 段落间空一行
   - 每行一句

3. **音频配置**
   - 如果有 LRC 文件，先上传 LRC 自动解析
   - 然后手动微调不准确的部分
   - 没有 LRC 文件时，可以手动设置时间轴

4. **数据备份**
   - 定期导出文章数据
   - 重要文章建议单独导出备份

5. **人名配置**
   - 如果文章中有很多人名，建议配置人名列表
   - 练习时这些名称会被自动忽略，提高效率
