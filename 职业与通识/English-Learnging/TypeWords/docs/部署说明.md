# 项目部署说明

## 📦 构建项目

首先需要构建生产版本：

```bash
npm run build
```

构建完成后，会在 `dist` 目录生成生产文件。

## 🚀 部署方式

### 方式一：Vercel 部署（推荐）

项目已配置 Vercel，可以直接部署：

1. **安装 Vercel CLI**（如果还没有）：
```bash
npm i -g vercel
```

2. **登录 Vercel**：
```bash
vercel login
```

3. **部署到生产环境**：
```bash
vercel --prod
```

或者直接推送代码到 Git 仓库，Vercel 会自动部署。

### 方式二：阿里云 OSS + CDN 部署

如果使用阿里云 OSS：

1. **设置环境变量**（在 `.env` 文件或系统环境变量中）：
```bash
OSS_REGION=your-region
OSS_KEY_ID=your-access-key-id
OSS_KEY_SECRET=your-access-key-secret
OSS_BUCKET=your-bucket-name
```

2. **构建并部署**：
```bash
npm run build-oss
npm run deploy-oss
```

或者直接：
```bash
npm run build
npm run deploy-oss
```

### 方式三：静态文件服务器部署

1. **构建项目**：
```bash
npm run build
```

2. **将 `dist` 目录内容上传到服务器**：
   - Nginx
   - Apache
   - 其他静态文件服务器

3. **Nginx 配置示例**：
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### 方式四：预览构建结果

在部署前，可以本地预览构建结果：

```bash
npm run build
npm run preview
```

## 📝 部署前检查清单

- [ ] 确认所有功能已测试通过
- [ ] 检查环境变量配置
- [ ] 确认 API 地址配置正确
- [ ] 检查路由配置（SPA 应用需要配置重定向到 index.html）
- [ ] 确认构建无错误和警告

## 🔍 常见问题

### 1. 路由 404 问题

SPA 应用需要配置服务器将所有路由重定向到 `index.html`。

**Nginx 配置**：
```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

**Vercel 配置**（已自动处理）：
Vercel 会自动处理 SPA 路由。

### 2. 静态资源路径问题

如果部署到子目录，需要修改 `vite.config.mts` 中的 `base` 配置：
```typescript
base: '/your-subdirectory/'
```

### 3. 环境变量

生产环境的环境变量需要在部署平台配置，不要提交到代码仓库。

## 🎯 快速部署命令

**Vercel 部署**：
```bash
npm run build && vercel --prod
```

**OSS 部署**：
```bash
npm run build && npm run deploy-oss
```
