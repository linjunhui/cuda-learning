# 1个核心结论 + 2个关键支撑点 + 明确的后续步骤。​

1个核心结论 + 2个关键支撑点 + 明确的后续步骤。​
•
先说核心结论：第一句话就点明最重要的结果或现状。
◦
例如：“张总，您要的第三季度销售数据分析，我已经整理好发您邮箱了。”
悦悦原创文档-禁止倒卖

•
再用关键点支撑：用一两个要点简要说明原因、依据或关键进展。
◦
例如：“数据对比了去年同期和本季度各月的情况，并重点标注了波动较大的部分。”
•
最后明确下一步：告知对方后续安排，或提出你需要他做的决策。
◦
例如：“您先过目。针对其中标注的异常数据，我初步分析了原因，如果您认为有必要，我们
可以约个时间简短讨论一下。”
在不同场景下的运用
•
在线上/线下会议发言时：​
◦
可以先说：“我同步一下XX项目的进展。”​
◦
然后直接套用上面的结构。语速可以稍慢，确保清晰。
◦
说完后，可以表示“我这边的情况就是这样”，然后将发言权交回。
•
当领导突然询问进度时：
◦
不要慌张或从头细说。立刻给出核心结论：“王经理，您问的合同流程，法务部已经审核通过
了。”
◦
补充关键点：“是按加急流程处理的。”
◦
说明下一步：“预计今天下午能拿到扫描件，我收到后第一时间发给您。”
•
进行书面汇报（邮件/文档）时：​
◦
标题/开头就要体现核心结论，例如：“【进展汇报】XX项目：用户测试已全部通过”。​
◦
正文分点列出关键支撑信息，如测试时间、覆盖率、问题修复情况等，并附上相关文件链接。
◦
结尾务必写清楚下一步需要谁、做什么、何时做。
如果汇报中被挑战或提问这很常见，不必视为对你个人的否定。
•
先倾听确认：“您是指XX部分可能存在风险，对吗？”​
•
如果已有准备：可以基于事实和数据简要解释。
•
如果不确定：坦诚地说：“您提到的这个点非常关键，我目前的数据/信息还不充分，需要再核实
一下。我能在今天下班前给您一个确切的回复吗？”
•
如果话题跑偏：可以温和地将讨论拉回主线：“关于您提的A点，我们稍后可以详聊。我先用半分
钟把原计划中剩下的B点关键情况说完？”​
汇报的核心是有效传递信息。充分的准备和清晰的结构，能给你带来更多的底气。
