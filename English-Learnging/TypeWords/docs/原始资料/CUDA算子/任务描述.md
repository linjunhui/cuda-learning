## 已总结的算子

### 1. GEMM (General Matrix Multiply)
- **位置**: `/home/jonson/cuda-learning/LeetGPU/2_matrix_multiplication/`
- **实现**: 
  - 朴素实现 (`matrix_multi.cu`)
  - 分块优化实现 (`matrix_tile.cu`)
- **关键知识点**:

  - 内存访问模式：合并访问 vs 跨步访问

  - 矩阵转置：为什么需要转置B矩阵，如何实现
  - 数据重用：如何通过分块实现O(T³)计算但O(T²)内存访问
  - 同步机制：__syncthreads()的作用和使用时机

### 2. Softmax
- **位置**: `/home/jonson/cuda-learning/LeetGPU/softmax/`
- **实现**:
  - 朴素实现 (`softmax_naive.cu`) - 三阶段：找最大值、计算指数和、归一化
  - 优化实现 (`per_token_softmax.cu`) - 在线安全softmax，使用warp级原语
- **关键知识点**:
  - 数学定义：Softmax公式和概率归一化
  - 数值稳定性：为什么需要max trick，数学证明
  - 归约操作：如何并行找最大值和求和
  - Warp级原语：__shfl_xor_sync的使用和优势
  - 区间合并：如何合并不同最大值的区间，缩放因子计算
  - 两级归约：warp内归约和block内归约
  - MD数据结构：同时维护最大值和分母的设计

### 3. Reduction
- **位置**: `/home/jonson/cuda-learning/LeetGPU/reduction/`
- **实现**: 基于共享内存的树形归约
- **关键知识点**:
  - 树形归约：二叉树归约模式，log₂(N)步数
  - 同步机制：__syncthreads()在归约中的关键作用
  - Bank冲突：共享内存bank的组织和冲突避免
  - 两阶段归约：block内归约和block间归约
  - 填充优化：如何通过padding避免bank冲突

### 4. ReLU
- **位置**: `/home/jonson/cuda-learning/LeetGPU/8_ReLU/`
- **实现**: 逐元素操作，每个线程处理一个元素
- **关键知识点**:
  - 逐元素操作：为什么ReLU适合GPU并行
  - 内存绑定：ReLU是内存受限还是计算受限
  - 梯度流动：ReLU在深度网络中的作用
  - 合并访问：如何确保内存访问的合并

### 5. 1D Convolution
- **位置**: `/home/jonson/cuda-learning/LeetGPU/6_1D_Convolution/`
- **实现**: 每个线程计算一个输出元素
- **关键知识点**:
  - 数学定义：卷积的数学公式
  - 并行化策略：如何将卷积并行化
  - 内存访问：输入和kernel的访问模式
  - 有效填充：输出大小的计算

### 6. ALiBi (Attention with Linear Biases)
- **位置**: `/home/jonson/cuda-learning/LeetGPU/Attention_with_Linear_Biases/`
- **实现**: 
  - 优化实现 (`ALiBi_gemini.cu`) - 使用 Warp-level Reduce 优化的注意力实现
- **关键知识点**:
  - ALiBi 数学原理：线性偏置函数 b(i, j) = -alpha * |i - j|
  - 位置编码对比：ALiBi vs 传统位置嵌入
  - 因果注意力：与因果 mask 的兼容性
  - 并行化策略：一个 Block 处理一行输出（one row per block）
  - Safe Softmax：最大值技巧在 ALiBi 中的应用
  - Warp-level Reduce：两级归约策略（warp 内 + 跨 warp）
  - Shuffle 指令：__shfl_down_sync 的使用和优势
  - 完整流程：从注意力分数计算到最终输出的逐步流程
